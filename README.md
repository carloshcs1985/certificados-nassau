# Certificados Digitais — Nassau

Controle de validade dos certificados digitais (e-CNPJ / e-CPF) do grupo Nassau. Web app instalável no iPhone (Safari → Compartilhar → Adicionar à Tela de Início).

- Dados no Supabase (projeto `certificados-nassau`), protegidos por RLS: qualquer pessoa lê a planilha Nassau e envia solicitações; só o administrador altera e vê a planilha pessoal e as solicitações.
- Nada de senhas de certificado neste sistema.
